# ReelStudio caption templates
Locate the ReelStudio checkout and read templates/AUTHORING.md. Consult templates/_docs/checklist.md before delivery, and the relevant _docs references for metadata, controls, timing, or tags. Inspect an existing template with a similar effect.

A template lives in templates/<id>/ with template.json and style.scss. The folder name identifies it. Use a distinct ID for a new design and preserve existing IDs used by saved projects. The build compiles Sass into flat style.build.css; runtime rendering and saved projects consume flat CSS.

Caption elements are .segment, .line, and .word. Animations are paused and sampled by changing animation-delay each frame: anchor animations to the documented playhead variables. CSS transitions cannot express this sampled rendering. Every exposed control becomes a --tscaps-<id> variable; ensure the stylesheet actually reads it. Semantic tags are not automatically generated by an LLM in the local editor: use real existing tags, manual tags, or implement tagging only if requested.

Implement the requested look with readable text and stable layout. Check long captions, punctuation, mixed Hindi/English text, the active-word state, and the first/last frame of each animation. Run pnpm templates:build and pnpm templates:contract from the checkout. Inspect the gallery preview and a short captioned export when browser access and a video are available. If only code validation is possible, state that visual/export verification remains unperformed. Do not claim a finished video from template source alone.
