REELSTUDIO · DESKTOP BETA 0.2.0-beta.1

Your next reel, from a chat.

Browse templates, Auto Edit an existing project, preview it and export a video. For Codex local desktop chats and Claude Code.

1. Install the prerequisites

  • Node.js 22 or newer (includes npm).
  • Google Chrome.
  • Codex desktop with its CLI available, or Claude Code. Use a local chat, not a cloud-only chat.
  • A ReelStudio account and internet connection. This beta does not include paid service credits or bypass account limits.

2. Extract the entire ZIP, then install

Mac: open Install-Mac.command. Windows: open Install-Windows.cmd. Linux: run sh install-linux.sh in the extracted folder.

Choose 1 for Codex or 2 for Claude Code. The installer checks prerequisites, copies the plugin to a permanent folder and installs its browser runtime from npm. Keep the internet connected. No administrator access is required.

If your system blocks the launcher, use your terminal in the extracted folder:

node scripts/install.mjs --host=codex

For Claude Code, replace codex with claude. To check prerequisites without changing anything:

node scripts/install.mjs --check

3. Restart and start a new local chat

Use ReelStudio to show templates and open my projects.

Sign in inside the dedicated Chrome window. Import your footage and generate captions there. Copy the project URL from that window into your chat:

Auto Edit this project with Study Notes: [paste your project URL]
Show me the preview.
Export this project as MP4.

The finished file is saved locally. Your project remains editable in ReelStudio.

If automatic registration is unavailable

The installer prints a Marketplace folder. Keep that exact path. With the appropriate CLI installed, replace PASTE_MARKETPLACE_FOLDER below:

Codex:

codex plugin marketplace add "PASTE_MARKETPLACE_FOLDER"
codex plugin add reelstudio-desktop@reelstudio-desktop-beta

Claude Code (run these in your terminal; Windows users may need this manual step):

claude plugin marketplace add "PASTE_MARKETPLACE_FOLDER"
claude plugin install reelstudio-desktop@reelstudio-desktop-beta

Then restart the app. If you only have Codex desktop and no CLI, install the official Codex CLI first. These commands register this private beta; they do not publish anything.

What to expect in this beta

  • Video import and transcription are done in the ReelStudio browser first.
  • The plugin uses a separate Chrome profile. Sign in again even if already signed in in normal Chrome. Local projects from another browser need importing.
  • Keep its Chrome window open during edits and export. Only one editing/export job runs at a time.
  • Save your work and restart the plugin session before changing projects. Avoid using Claude and Codex on the same plugin browser simultaneously.
  • ZIP extraction, setup and packaged tool discovery are tested on macOS. Host registration and full video editing/export should be confirmed by beta testers. Windows and Linux launchers have not been tested on physical devices.

Updates, removal and privacy

Close the plugin session before running a newer beta installer. Each version installs into its own folder under ~/.reelstudio-plugin/plugins. The installer preserves your browser session and exports. If an older ReelStudio plugin is enabled, disable it before enabling this beta to avoid duplicate tools.

Remove through your host's plugin controls, or run codex plugin remove reelstudio-desktop@reelstudio-desktop-beta / claude plugin uninstall reelstudio-desktop@reelstudio-desktop-beta. Removing the plugin does not erase its saved browser profile or exported videos.

The ZIP contains software only. Browser login stays on your computer in ~/.reelstudio-plugin/browser-profile; exports go to ~/.reelstudio-plugin/exports. ReelStudio account uploads follow the website's storage policy. Never send your profile folder, passwords or tokens to support.
